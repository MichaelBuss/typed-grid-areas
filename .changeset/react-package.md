The React adapter, formerly `typed-grid-areas/react`, as a package of its own: `npm i typed-grid-areas @typed-grid-areas/react`, then `import { createGridComponent } from "@typed-grid-areas/react"`. Same API and behaviour as before: a component per definition, a slot component per area, `asChild`, `nest`, the CSS hoisted once per definition, and the development warnings. Needs React 19 or later.
